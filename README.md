# Global Capital Insights (GCI) 🚀

**Global Capital Insights** is a high-performance financial intelligence portal designed for real-time market analysis, geopolitical tracking, and institutional investment insights.

## 🌐 Live Demo
You can visit the live portal here: [https://gilberu.github.io/globalcapitalinsights/](https://gilberu.github.io/globalcapitalinsights/)

## ✨ Key Features
* **Live Intelligence:** Real-time feed of high-impact financial events.
* **Crisis Tracker:** Geopolitical monitoring (U.S. - Iran relations).
* **Executive Digital Literacy:** Specialized training content for modern decision-makers.
* **Glassmorphism UI:** A sleek, modern interface optimized for data readability.
* **SEO Optimized:** Fully configured with `sitemap.xml`, `robots.txt`, and `ads.txt`.

## 🛠️ Tech Stack
* **Architecture:** MVC (Model-View-Controller) pattern for clean code separation.
* **Frontend:** HTML5, CSS3 (Custom Variables & Glassmorphism), JavaScript (ES6+).
* **Performance:** Optimized for fast rendering and low latency.

## 📈 Strategic Focus
The portal focuses on high-CPC niches, including:
* Institutional debt restructuring (Venezuela 2026).
* Central Bank Digital Currencies (mBridge & BRICS Bridge).
* Quantum-resistant banking infrastructure.
